# نظام إدارة الكنيسة — دليل الإعداد

## هيكل الملفات
```
church-system/
├── index.html                    ← التطبيق الكامل (صفحة واحدة)
├── css/style.css                 ← التصميم الكامل
├── js/
│   ├── core.js                   ← API، المصادقة، الأدوات المشتركة
│   ├── members.js                ← إدارة الخدام والمخدومين
│   ├── attendance.js             ← تسجيل الحضور والعرض الشهري
│   ├── dashboard.js              ← لوحة التحكم وأعياد الميلاد
│   ├── qr.js                     ← توليد ومسح رموز QR
│   ├── users.js                  ← إدارة المستخدمين والطلبات
│   └── app.js                    ← التوجيه والتشغيل
└── google-apps-script.js         ← الصق في Apps Script
```

---

## الخطوة 1 — إعداد Google Sheets

1. أنشئ جدول بيانات Google جديداً
2. اضغط **Share** → غيّر إلى **Restricted** (محدود)
3. انتقل إلى **Extensions → Apps Script**
4. احذف الكود الموجود والصق محتوى `google-apps-script.js` كاملاً
5. **غيّر** `API_SECRET` في السطر 17 إلى كلمة سر طويلة من اختيارك:
   ```js
   const API_SECRET = 'كلمةSرية_طويلة_2024!xK9pLm';
   ```
6. احفظ (Ctrl+S)

---

## الخطوة 2 — نشر Apps Script

1. **Deploy → New Deployment**
2. اختر نوع **Web App**
3. الإعدادات:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. اضغط **Deploy** وانسخ رابط الـ Web App

---

## الخطوة 3 — ربط الموقع بـ Sheets

افتح `js/core.js` وعدّل في الأعلى:
```js
const CONFIG = {
  API_URL:    'https://script.google.com/macros/s/XXXXX/exec',
  API_SECRET: 'كلمةSرية_طويلة_2024!xK9pLm',  // ← نفس الموجود في Apps Script
};
```

---

## الخطوة 4 — رفع الموقع

ارفع المجلد كاملاً على GitHub Pages أو Netlify:

**GitHub Pages:**
1. ارفع الملفات لمستودع جديد
2. Settings → Pages → branch `main` → `/root`
3. رابطك: `https://USERNAME.github.io/REPO/`

---

## أول تسجيل دخول

1. اذهب لصفحة الموقع → تبويب **"إنشاء حساب"**
2. سجّل أول مستخدم — سيكون في انتظار الموافقة
3. ⚠️ **المشكلة:** لا يوجد مدير بعد! **الحل:** افتح Sheets يدوياً:
   - اذهب لتاب `Users`
   - ابحث عن الحساب الذي أنشأته
   - غيّر عمود `role` من `user` إلى `admin`
   - غيّر عمود `status` إلى `active`
4. الآن سجّل دخول كمدير
5. من **"إدارة المستخدمين"** وافق على باقي الطلبات

## التابات في Google Sheets

| التاب | المحتوى |
|---|---|
| `Users` | حسابات المستخدمين |
| `Sessions` | جلسات تسجيل الدخول النشطة |
| `PendingUsers` | طلبات التسجيل بانتظار الموافقة |
| `خدام_حضانة` | بيانات خدام الحضانة |
| `خدام_أولى_تانية` | خدام أولى وتانية ابتدائي |
| `خدام_تالتة_رابعة` | خدام تالتة ورابعة ابتدائي |
| `خدام_خامسة_سادسة` | خدام خامسة وسادسة ابتدائي |
| `خدام_إعدادي` | خدام الإعدادي |
| `خدام_ثانوي` | خدام الثانوي |
| `خدام_شباب` | خدام الشباب |
| `خدام_خريجين` | خدام الخريجين |
| `حضور_حضانة` | حضور خدام الحضانة |
| `حضور_أولى_تانية` | ... وهكذا لكل مرحلة |
| `مخدومين_حضانة` | مخدومو الحضانة |
| `مخدومين_أولى_تانية_ابتدائي` | مخدومو أولى وتانية ابتدائي |
| ... | ... حتى `مخدومين_خريجين` |
| `حضور_مخدومين_*` | حضور المخدومين لكل مرحلة |
| `ServiceProgram` | برنامج يوم الخدمة |

## الأمان

| الطبقة | الحماية |
|---|---|
| Google Sheets → Restricted | لا أحد يفتح الشيت مباشرة |
| API_SECRET | كل طلب يحمل كلمة السر |
| Session Token | كل طلب بعد تسجيل الدخول يحمل توكن |
| Session expiry | الجلسات تنتهي بعد 8 ساعات من عدم النشاط |
| Status check | الحسابات المعطّلة لا تستطيع الدخول |

## تغيير شعار الخدمة

افتح `js/dashboard.js` وعدّل:
```js
const VERSE = {
  text: '"نص الآية الكتابية هنا..."',
  ref:  'مت 5 : 16',
};
```
ثم ارفع الملف مجدداً.

---

## إعادة نشر Apps Script بعد التعديل

عند تعديل `google-apps-script.js`:
1. Deploy → **Manage Deployments**
2. اختر النشر الموجود → Edit (✏️)
3. Version → **New Version**
4. Deploy — الرابط لا يتغير
